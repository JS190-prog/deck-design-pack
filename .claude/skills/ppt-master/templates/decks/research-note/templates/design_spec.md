# Research Note — Design Specification

> 원저작 템플릿. 금융권 셀사이드 리서치 리포트에서 널리 통용되는 **비독점 편집 관례** — 리포트 헤더 밴드(리포트 유형·발간일·공개 등급), 투자의견 박스, 1/3 사이드바 + 2/3 본문, 우측 정렬 숫자의 촘촘한 표, `Figure n` 번호와 그림마다 붙는 `자료:` 줄, 굵은 상단 규칙선 + 가는 규칙선, 고지 문구 푸터 — 를 슬라이드 문법으로 새로 설계했다. 특정 증권사·리서치 기관의 상표·로고·서식·독점 UI를 복제하거나 번들하지 않는다. 브랜드는 `{{BRAND_MARK}}` 텍스트로만 존재하고, 비트맵·로고·사진 자산은 없다. 서체는 install-local Pretendard 락을 따른다 — 세리프 없이 규칙선·밀도·굵기만으로 "리포트"의 인상을 만든다.

## I. Template Overview

| Property | Description |
| --- | --- |
| **Template Name** | research-note |
| **Display Name** | Research Note (리서치 노트) |
| **Use Cases** | 금융·산업 리서치 브리핑, 시장 동향 보고, 투자 검토 요약, 분기 실적 분석, 추정치 변경 노트 |
| **Design Tone** | 밀도·정확·인용 가능 — 모든 수치에 단위·기간·출처가 붙는다 |
| **Theme Mode** | **Light paper** — 전 페이지 `#F5F3EF` 종이 바탕, 표·패널만 `#FFFFFF` |

한눈에 알아보는 표지: 페이지 맨 위 **헤더 줄(브랜드 | 리포트 유형 ··· 발간일 · 공개 등급) 아래 3px 네이비 규칙선**, 그 아래 단과 그림마다 다시 깔리는 **2px 네이비 상단선**, 그리고 모든 그림·표 밑의 **`자료:` 줄**. 장식은 없고 위계는 규칙선의 굵기 사다리로만 만든다.

**Anti-mood**: "마케팅 키노트", "그라디언트 SaaS 대시보드", "라운드 카드 갤러리", "아이콘 인포그래픽", "풀블리드 다크 히어로".

**Litmus test**: 페이지를 흑백으로 출력해 PDF 리포트 사이에 끼워도 어색하지 않고, 모든 그림·표에서 번호·단위·출처를 바로 찾을 수 있으면 통과. 버건디를 지웠을 때 의미가 사라지는 곳은 페이지당 1–2곳뿐이어야 한다.

### Color Rules

- **네이비가 구조, 무채색이 내용.** 네이비는 규칙선·박스·주 계열에만 쓰고 본문 글자에는 쓰지 않는다 (소제목·번호·라벨 예외)
- **틴트는 "추정/주목 열"이다.** 06의 2026E/2027E 열, 07의 변경 열, 04 스냅샷의 E 열, 05의 추정 막대가 같은 틴트를 공유한다 — 독자는 틴트를 보면 "추정치"로 읽는다
- **버건디는 페이지당 1–2곳.** 하향 ▼, 음수 성장률, 위험 '높음', Bear 결과값 변화율. 강조 장식으로 쓰지 않는다
- **포지티브 그린은 표 안의 ▲ 상향 조정에만.** 차트·제목·본문에 녹색 금지. Bull 시나리오도 녹색이 아니다
- **음수는 괄호 표기 `(1,830)`.** 색은 기본 본문색이고, 의미 있는 악화 신호일 때만 버건디
- **Forbidden**: 그라디언트, 그림자, 글로우, 투명도 겹침, 라운드 코너, 다색 카테고리 팔레트

## VI. Signature Design Elements

1. **헤더 줄 + 3px 네이비 상단 규칙선** — 모든 페이지 맨 위. 좌측 `{{BRAND_MARK}}`(네이비 700) `|` `{{REPORT_TYPE}}`, 우측 `{{DATE}} · {{CLASSIFICATION}}`. 이 한 줄이 덱을 "발간물"로 만든다
2. **규칙선 굵기 사다리** — 페이지 3px 네이비 → 단·그림·표 상단 2px 네이비 → 섹션 구분 1px `#B8B8B8` → 행 구분 1px `#DCDCDC`. 박스 테두리 대신 선의 굵기로 위계를 만든다
3. **Figure / 자료 쌍** — 그림·표마다 `Figure n` / `Table n`(네이비 600) + 제목(잉크 600), `단위:` 줄, 그리고 반드시 아래쪽 `#B8B8B8` 선 뒤에 `자료:` 줄. 출처 없는 그림은 이 템플릿에 없다
4. **1/3 사이드바** — 틴트 사이드바(요약·팩트)와 흰 스냅샷 패널이 좌측 368px을 차지하고 본문 784px이 그 옆에 붙는다. 사이드바 상단과 본문 상단선은 같은 y=128에 정렬
5. **투자의견 박스** — 표지의 유일한 네이비 면. 라벨(`투자의견`) → 40px 의견 → 회색 가는 선 → 한 줄 논지 → 하단 기준 문구
6. **영문 보조 라벨** — 단 제목 오른쪽 끝에 12px 회색 영문(Key Takeaways, Catalyst Calendar, Rationale, Methodology…). 리서치 리포트의 이중 표기 관례
7. **고지 문구 푸터** — 표지 포함 전 페이지 `{{DISCLAIMER}}` + 쪽번호(표지 제외). 코너 반경은 전부 0

## VII. Chart & Table Treatment

**차트**
- 그리드: 가로 헤어라인 `#DCDCDC` 1px 4개 + 기준선 `#707070` 1px. 세로 그리드·플롯 프레임 금지
- 축 라벨 12px `#707070` — y축 anchor end, x축 anchor middle. 추정 연도(E) 라벨은 네이비
- 라인: 주 계열 네이비 2.5px, 비교 계열 `#B8B8B8` 2.5px. 중간 점 마커 없이 **끝점 점 + 끝값 라벨**(주 계열 네이비 600, 비교 계열 회색)
- 막대: 실적(A) 네이비 솔리드, 추정(E) 틴트 채움 + 네이비 1.5px 외곽선. 값 라벨 12px Medium 잉크, 막대 위 8px
- 범례: `단위:` 줄과 같은 행 오른쪽 — 선 스와치 20px / 사각 스와치 12px
- 그림 구조(위→아래): 2px 네이비 상단선 → `Figure n` 캡션 → 단위·범례 → 플롯 → `#B8B8B8` 선 → `자료:` 줄
- **Forbidden**: 3D, 파이, 그림자, 그라디언트 채움, 3계열 이상(그림을 나눈다)

| Page | Marker |
| --- | --- |
| `05_figure_chart` (Figure 1, line) | `<!-- chart-plot-area: 100,212,604,552 -->` |
| `05_figure_chart` (Figure 2, bar) | `<!-- chart-plot-area: 716,212,1220,552 -->` |

**표**
- 흰 패널 + 2px 네이비 상단선, 헤더 13px 600 `#707070`, 헤더 하단 `#B8B8B8`, 행 구분 `#DCDCDC`, 표 하단 `#B8B8B8`
- 숫자 우측 정렬(06: 열 끝 −24px, 07·04: −8~−14px), 라벨은 좌측. 하위 항목은 16px 들여쓰기
- 합계 행: 700 + 위쪽 `#1A1A1A` 1px 선
- 추정 열은 헤더부터 표 하단까지 틴트 음영, 헤더 글자는 네이비
- 추정 변경 표: 기존 `#707070` / 변경 600 잉크(틴트 열) / 변화율 600 — ▲ `#2E6B3F`, ▼ `#8C1C13`, 비율 항목은 `%p`
- 표 아래 `주:` 줄과 `자료:` 줄(12px `#707070`)을 항상 함께 둔다

## IX. Anti-Pattern Checklist

| ✗ 금지 | 대안 |
| --- | --- |
| 출처 없는 그림·표 | 모든 그림·표 아래 `자료:` 줄 (+ 표는 `주:`) |
| 숫자 가운데·왼쪽 정렬 | 열 오른쪽 끝 정렬, 천 단위 쉼표, 음수 괄호 |
| 버건디 3곳 이상 / 장식용 버건디 | 하향·음수·위험 '높음'에만 페이지당 1–2곳 |
| 차트·본문에 녹색 | 녹색은 표 안 ▲ 상향 조정 전용 |
| 추정치를 실적과 같은 색으로 | 추정 열·막대는 네이비 틴트 |
| 라운드 코너·그림자·그라디언트 | 코너 0, 평면, 규칙선 굵기로 위계 |
| 카드 테두리로 구획 | 2px 네이비 상단선 + 헤어라인 |
| 세리프·다른 서체로 "리포트 느낌" | Pretendard 굵기 대비 + 규칙선 밀도 |
| 헤더 줄·고지 문구 생략 | 전 페이지 헤더 줄 + 3px 상단선 + 고지 푸터 |
| 본문 18px 미만 | 표 셀·주석만 15–16, 크롬만 11–13 |
| 로고·워드마크 이미지 번들 | `{{BRAND_MARK}}` 텍스트 |
| 3계열 이상 라인 / 파이 차트 | 그림을 나누거나 막대·표로 |
